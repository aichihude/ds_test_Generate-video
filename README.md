# PROMPT → VIDEO ｜ 一段提示词如何变成一段视频

一支 52.7 秒的 MG 动画（程序化矢量动效，非实拍、非模板）。内容不是"科普讲解"，
而是**把提示词送进管线后底层真实发生的事**，一步一步演给你看，最后把它变成一段视频。

## 观看

直接用浏览器打开 `index.html` 即可（无需服务器、无外部依赖、无字体下载）。

- 空格：播放 / 暂停　←→：前后 1 秒　R：重播
- 鼠标移到画面上会浮出进度条，可拖动定位
- 加 `?t=24.6` 可以直接跳到某一秒定格（用于校对构图）
- 加 `?auto=1` 自动开播（跳过封面）

## 分镜（总长 52.7s，30fps 设计基准，1920×1080）

| # | 时间 | 镜头 | 画面在讲什么 |
|---|------|------|--------------|
| 01 | 0.0–3.9 | 初始化 | 空域中点亮的种子与贯穿全片的光轴 |
| 02 | 3.9–9.3 | 提示词注入 | 逐字写入的提示词，参数芯片，暖色数据流 |
| 03 | 9.3–14.5 | 分词 · 编码 | 字符→token→768 维语义向量 |
| 04 | 14.5–21.3 | 潜空间扩散 | 纯噪声场按 28 步去噪，显影出地形 |
| 05 | 21.3–28.5 | 时序一致性 | 121 帧胶片条沿运动轨迹逐格对齐 |
| 06 | 28.5–33.9 | 解码重建 | 潜变量展开为像素，通道分离后成帧 |
| 07 | 33.9–39.5 | 超分 · 修复 | 由糊到清，540p → 1080p |
| 08 | 39.5–46.9 | 播放 | 播放器 UI、时间码、进度条，画面缓推 |
| 09 | 46.9–52.7 | 签名 · 循环 | 三个 take、标题落版、黑场接回开头 |

> 时间表由 `node tools/doccheck.js` 与代码比对，防止文档与实现脱节。

## 视觉语言

- **同一片空间**：九个镜头共用一套底层氛围（深空底 + 极光 + 透视网格 + 飘浮代码 + 扫描线 + HUD 边框），
  镜头之间只换景不换皮，靠一条不断裂的"光流"（琥珀→青→紫）串场。
- **色彩语义**：凡是"提示词/人类输入"一律暖金 `#FFC46B`；凡是"机器生成"一律青紫 `#5FE3FF → #9B7DFF`；
  完成态用薄荷 `#7BF2C0`。
- **画中画同源**：全片出现的"画面内容"都由 `js/film.js` 程序化生成（体素光带地形），
  所以潜空间里显影的东西 = 最后播放的东西 = 结尾三张 take。

## 文件结构

```
index.html          播放器外壳（canvas + 颗粒/暗角 DOM 层 + 控制条）
js/util.js          时间轴、缓动、字体与色彩令牌、绘图原语
js/film.js          "被生成的那段视频"：体素地形栅格 + 噪声贴图 + 去噪波次
js/bg.js            全局氛围层：深空底、极光、透视网格、飘浮代码、HUD、扫描线、字幕
js/shots.js         九个分镜的绘制逻辑 + 镜头间连续性层 + 切点闪光
js/main.js          主循环、播放控制、逐帧校验钩子
tools/harness.js    开发用：Node 里的 Canvas2D + DOM 运行壳（被下面两个脚本共用）
tools/lint.js       开发用：排版/几何静态检查（文字裁切、出血、重叠、坐标异常）
tools/record.js     开发用：把真实分镜代码的 Canvas2D 调用录成 JSON
tools/rasterize.py  开发用：用 Pillow 回放指令流，离屏出图校验
tools/contact.py    开发用：把校验帧拼成分镜总览
tools/doccheck.js   开发用：校验文档里的时长/分镜表与代码一致
preview/            逐帧校验图（_contact_sheet.png 为总览）
```

## 关于 tools/

本地开发时无法拉起无头浏览器（沙箱禁止命名管道），于是写了一套"录放 + 静态检查"链路：

- `harness.js` 在 Node 里提供最小 Canvas2D + DOM，真实执行分镜代码并录制绘制指令；
- `lint.js` 基于录制结果做排版检查：文字被 clip 裁切、出血出安全区、大块文字重叠、
  非有限坐标、超大元素、阴影开销，并统计每个分镜的绘制负载；
- `rasterize.py` 用 Pillow 按真实变换/渐变/裁剪/混合模式回放成 PNG，用来目视校对构图配色。

它只用于**校对**，不是运行时依赖——动画本身在浏览器里跑的是原生 Canvas2D。

```bash
node tools/lint.js                   # 排版检查 + 每镜绘制负载
node tools/lint.js --per=10          # 每镜取 10 个采样点（更严）
node tools/doccheck.js               # 文档与代码一致性
DSH_TIMES=1.8,12.6,24.6 node tools/record.js   # 录制指定时间点
python tools/rasterize.py            # 输出 preview/*.png
python tools/contact.py              # 拼总览图
```
